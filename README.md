# Saathi - Senior Companion App

An elderly-friendly app for safety, health and companionship. Built for Hack for a Social Cause, VBYLD 2027 (Theme 9: Elderly Care & Healthy Ageing).

## Problem
Many senior citizens live alone, forget medicines and pension dates, and feel lonely.

## Features
- One-tap SOS with live location sent to family
- Volunteer visit log (BP, mood, notes)
- Reminders with alarm and voice (pension, check-ups, medicines, schemes)
- Live-location map with "Take me home"
- Weekly Day Camps and friends list to reduce loneliness
- Large text, simple design, English and Hindi

## How to run
1. Clone this repo
2. In the terminal: `python3 -m http.server 8000`
3. Open http://localhost:8000 and allow location access
